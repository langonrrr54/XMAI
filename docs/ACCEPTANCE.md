## 验收中发现并修复的问题

1. **审校后状态被覆盖**：重新写摘要时把 `reviewed` 重置为 `drafted`，已改为保留审校/发布状态。
2. **流式请求不重试**：`chatStream` 遇到 5xx/429 直接失败，已加入最多 3 次重试；仅在尚未收到正文时重试，避免重复内容。
3. **停止被当作错误**：用户主动停止会触发 `error` 状态，已增加 `stopping` 标记，停止后为 `idle` 且不弹错误。
4. **章节续写起点**：中断草稿为 `planned`，原逻辑会把它当作最后一章导致跳过；已改为按 `lastCompleted` 续写，草稿章节会被重写。
5. **超时/额度错误不直观**：现在会带 HTTP 状态与响应片段；超时有独立提示。
6. **单章写作被页面切换中断**：原 `chapters:write` 直接调用 `writeChapter`，不走调度器，切页后进度条消失、任务中断；已改为统一走 `writingRunner.writeOne()`，与批量写作共用进度条/日志/暂停/停止。
7. **错误被吞成假消息**：`run()` 吞掉异常只写 `status.error`，导致 `writeOne` 报「写作完成后未找到章节」掩盖真实错误；已改为 `run()` 抛出异常，`pipeline:start` 仅吞掉未处理拒绝。

## 未覆盖 / 限制

- **真实模型质量**：mock 只能证明记忆被正确注入、流程正确；真实文风、剧情一致性仍需接真实模型抽查。
- **数小时连续运行**：用 60 章压缩 soak（14.3s）验证机制；未做真实数小时挂机。状态轮询、事件上限（300 条）、每章落盘均已验证有界。
- **系统文件对话框**：导出「另存为」、封面「上传图片」依赖系统原生对话框，自动化测试使用静默导出与 API 路径，未自动点击原生窗口。
- **EPUB 商业阅读器**：已用 ZIP 结构与 XML 解析器校验，未在 Apple Books / 多看中实际打开。
- **番茄发布**：未做真实账号发布（需要用户登录态与录制接口）。
